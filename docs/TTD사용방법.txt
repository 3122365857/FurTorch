☆ 수정날짜 : 2026-02-22

  ★ TTD란? (Torchlight Tracker Diablo)
  - TTD(Torchlight Tracking Diablo)는 토치라이트 인피니트 게임 플레이 중
   맵핑 시간, 수익률, 경험치 효율 등을 자동 분석해주는 도구입니다.

  - TTD를 만든 목적은 토치라이트를 사랑하는 팬으로써 파밍의 재미를 좀더 높여보고자
    다듬다보니 여기까지 온거 같습니다. 토치라이트 열성팬이 만든 "팬아트 작품"으로 봐주세요.

  - 도움주신분 : XD님,Pyo님,제로님,고인물님,샤프님,리스틸님,메밀묵님,스트리머님들 등 외 많은 토치 유저님들
  
  - 참고사이트 : XD공식사이트,tlidb,네이버라운지,디시

  - TTD 다운로드 (구글드라이버)
    https://drive.google.com/drive/folders/1vqdXS4oNRkVy1r8-1DkWVC5mvvsUhreF?usp=sharing

 ★ 작동원리
   게임 ‘로그 오픈(Log Open)’시스템 지원해주는 기능을 통해 내 컴퓨터의 로그 파일을 읽어
   가방 아이템 수량 변화를 기반으로 수익을 계산합니다.
   
   로그 경로 = \Torchlight Infinite\Game\UE_game\Torchlight\Saved\Logs 
   (토치라이트 개인마다 설치위치가 다를수도있어요 스팀이든 전용클라 모두 같은 경로구조)

   게임에 메모리 방식으로 읽고쓰는게 아닌 Log.txt파일을 읽은후 필요한 값만 보여주는 방식입니다.

 ★ 사용목적
   1) 시간당 수익율 체크 용도 (파밍 선택지 고민시 사용)
   2) 렙업 효율을 위한 체크 용도 (지역선택,펫선택 체크용)
   3) 상하차 아이템 시세 확인용도
   4) 초보자를 위한 가이드 및 팁
   6) 파밍 재미 증가 및 기록용

 ★ 사용방법
   1) 토치라이트(스팀/전용클라)선택해서 실행을 합니다
   2) 캐릭터를 선택하고 마을에 입장합니다
   3) ESC키 > 기타설정 > 로그오픈(log open) 클릭 합니다 (로그아웃 아닙니다.)
   4) TTD.EXE 를 실행합니다
   5) 캐릭터가 마을에 있는상태에서 TTD에 초기화 버튼 클릭 합니다
   6) 가방 정렬 버튼 1회 클릭 합니다. (3번째 가방 정리 추천)
   - 이미정렬한 가방은 정렬기억이 되지 않으니 다른가방 혹은 분해,창고이용해서 정렬기억해결
   7) 런 시작 (용자런,이계런,보스런,차원 등등)
   
 ★ 버젼별 관리팁
  - 버젼별 폴더로 관리하시는것을 추천합니다.
  - 이전 버젼에 "드롭기록표 폴더"만 새버젼으로 옮기시면 파밍기록 이어나가실수있어요
  - 참고로 시세기록표 폴더에 데이터는 v2.7.9 버젼부터 기본 포함됩니다 
  - 수익측정 중에 시간을 일시정지 하고싶을때 
    (가방열기 = M시간 일시정지 /  T시간 일시정지) 단 T시간은 장소제한 없이 정지

  ☆ Scouter.exe(스카우트) 사용법
  - Scouter.exe를 실행할 필요가 없습니다.
  - TTD실행 > 실시간기록 탭 > 스카우트 연결 체크 유무에 따라 스카우트가 켜지고 꺼집니다
  - TTD에서 초기화해서 사냥터에 아이템을 줍게되시면 스카우트 실시간 드롭리스트가 작동됩니다
  - 맵입장시 자동으로 선명해지고 맵밖으로 나가면 자동으로 반투명 전환
 
  ☆ 스카우트 실행창에 있는 네모이미지의 기능
  - 스카우트 창을 이동할때 사용합니다
  - 왼쪽 마우스 클릭할때마다 반투명 및 복원 됩니다  
  - 오른쪽 마우스 클릭하게되면 = 설정(종료/글자색,크기수정/표기/창크기)
  - 스카우트 설정값은 config_mini.json에 저장됩니다
  - 주의 Scouter.exe 파일명 이름 변경금지 / 이름 변경시 종료 및 동기화 문제가 발생될수 있습니다
  
  ☆ TTD 입력창에 간혹 커서입력이 잘안되는경우 (시세목록탭-검색/실시간기록탭-숨김필터)
  - 윈도우 바탕화면 아무곳이나 클릭 혹은 TTD실행창외 다른 창을 클릭을 하시면 해결됩니다.

 ★ 아이템 시세 적용방법
